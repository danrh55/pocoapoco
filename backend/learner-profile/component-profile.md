# Learner profile component profile

## Responsibility

The learner profile represents information that helps tailor communication challenges to the learner. This includes interests, current knowledge, and observed needs in understanding and expressing language.

## Owns

- A learner-specific representation that can inform the conversation and its supporting work.
- A view of learning that can reflect both comprehension and generation without assigning a fixed rank or treating them as exclusive stages.

## Collaborates with

- **Conversation** and **Agent**, which use learner context to shape the exchange.
- **Comprehension** and **Tools**, which may use learner context when assessing needs or providing support.

## Does not own

The profile does not conduct the conversation, assess individual messages, or provide learning tools.

## Deferred to a specification

Profile fields, how observations update the profile, and how long-term information is stored.
