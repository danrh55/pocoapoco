# Generation tools profile

## Responsibility

Generation tools help the learner develop language they want to express. They work with learner-authored language, including written sentences.

## Owns

- Tools that help the learner notice and attempt corrections in their own writing.
- Tools that provide deliberate practice in expressing meaning.

## Collaborates with

- **Conversation**, which provides the context for the learner's expression and incorporates practice into the ongoing challenge.
- **Learner profile**, which can inform relevant and appropriately challenging support.

## Does not own

Generation tools do not support understanding of agent messages; that is the purpose of Comprehension tools. They do not replace the conversation as the challenge interface.

## Deferred to a specification

Correction and practice formats, invocation policy, and input and output formats.
